## About this entry

The reply is honest about the two things every out-of-office
hides: the size of the unread pile and the order in which it
will actually be answered. A specific number, 412 unread
messages, makes the honesty concrete instead of vague, and the
triage rule — answered in order of how loudly each sender can
complain to the manager — is the part nobody admits out loud.
That is what makes it painfully honest rather than merely blunt.
It stays polite enough to survive a manager because it never
insults anyone, never swears, and never refuses to reply: it
only describes the queue and the order honestly. The judge
weighs honesty first, then politeness, then the turn of phrase,
and this line leads with honesty while keeping the phrasing
professional. The program holds the line, checks it against
the two hundred character cap and the single-sentence rule,
and writes it to /output/entry.txt exactly as the bounty
requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
